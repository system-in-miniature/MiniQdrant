# MiniQdrant

MiniQdrant is a direct-first Python reference implementation of filtered vector
search, versioned segments, and durable recovery.

The implementation is in progress. Its frozen design is documented in
[`docs/superpowers/specs/2026-07-27-miniqdrant-reference-project-design.md`](docs/superpowers/specs/2026-07-27-miniqdrant-reference-project-design.md).
